# Support policy

ReviewReply AI support covers confirmed defects in the unmodified distributed source and clarification of the included installation documentation. It does not include server administration, custom features, third-party account approval, AI usage fees, payment-provider fees, legal advice, or compatibility repairs for buyer modifications.

Before requesting support, include the application version, hosting platform, Node.js version, database version, the safe error reference shown by the UI, and reproduction steps. Never send passwords, API keys, webhook secrets, database URLs, or full environment files.
